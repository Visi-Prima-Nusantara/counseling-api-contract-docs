string

Get list of report created by me, my-students, my-kids, teachers, students

status
string (BullyingReportStatus)
Enum: "0" "1" "2" "3"

Filter reports by status, can be REVIEW = 0, FOLLOW_UP = 1, DONE = 2, REJECTED = 3

Create a new bullying report

Create a new bullying report, a report can only be created by a student or teacher.

Request Body schema: multipart/form-data
required
types
required
string

Types of bullying, can be PHYSICAL = 0, VERBAL = 1, SOCIAL = 2, CYBER = 3, OTHER = 4, comma separated, e.g. "0,1,2"

other_type
string

Other type of bullying, if types contains OTHER = 4, this field is required otherwise will be empty string

report_to
required
string

Who the report is addressed to, can be teacher or admin

date
required
string

ISO 8601 date string, e.g. "2023-10-01T12:00:00Z"

locations
required
string

Locations of the incident, can be CLASSROOM = 0, CANTEEN = 1, SCHOOL_YARD = 2, TOILET = 3, OTHER = 4, comma separated, e.g. "0,1,2"

other_location
string

Other location of the incident, if locations contains OTHER = 4, this field is required otherwise will be empty string
